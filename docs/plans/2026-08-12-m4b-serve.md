# fpd M4b — `fpd serve`

> Execute task-by-task. Every task ends at a hard stop for review and commit.

**Goal:** A reverse proxy that terminates TLS, fingerprints the client, forwards to an upstream over plain HTTP, and injects the result as headers so any application in any language can log it.

**Architecture:** New module `serve.rs` in `fingerprint-probe`, plus `fpd serve`. The M0 S2 spike proved hyper can serve a connection whose HTTP/2 preamble was already consumed, using a `Replaying` adapter. This is where that finally gets used for real. Upstream is HTTP/1.1 only in v1, which is the standard sidecar shape and avoids h2-to-h2 proxying.

**Tech Stack:** hyper 1 (server + client), hyper-util, http-body-util, tracing. Existing probe, core, h2.

## Global Constraints

- Loopback and explicit binds only. No wildcard default.
- **Inbound `X-FP-*` headers are stripped before injection, without exception.** Otherwise a client forges its own verdict. This is the one rule in the milestone that is a security property rather than a nicety.
- Header values are not logged, with the `user-agent` exception already documented. Cookie and authorization values never appear in a log line.
- Every connection is bounded: handshake timeout, capture timeout, upstream timeout, max concurrent connections.

## Commit Protocol

**The implementer never runs `git commit` or `git push`.** Stop at each task, print the command, wait.

---

## What is new here, versus everything before it

Every milestone so far produced code that runs once and exits. This one runs
indefinitely in front of a production application, which changes what "correct" means:

- **A panic is an outage**, not a failed test. The parsers are already panic-free and
  fuzzed, which is why that work came first.
- **A slow client is an attack.** One-shot code can block; a server cannot.
- **Fingerprinting must never break the site.** If parsing fails, the request still gets
  proxied, annotated as `unparsed`. A fingerprinting sidecar that can 500 the
  application is worse than no sidecar.

```rust
/// The security property of this milestone. A client that sends its own
/// X-FP-Verdict must not have it reach the upstream, or it forges its verdict.
#[test]
fn inbound_fp_headers_are_stripped_before_injection() {
    let mut h = HeaderMap::new();
    h.insert("x-fp-verdict", "chrome-macos".parse().expect("v"));
    h.insert("X-FP-Mismatch", "false".parse().expect("v"));
    h.insert("x-real-header", "kept".parse().expect("v"));

    strip_inbound(&mut h);

    assert!(h.get("x-fp-verdict").is_none());
    assert!(h.get("x-fp-mismatch").is_none());
    assert_eq!(h.get("x-real-header").map(|v| v.as_bytes()), Some(&b"kept"[..]));
}

#[test]
fn stripping_is_case_insensitive_because_header_names_are() {
    for name in ["X-FP-JA4", "x-fp-ja4", "X-Fp-Ja4"] {
        let mut h = HeaderMap::new();
        h.insert(name.to_lowercase().parse::<HeaderName>().expect("n"), "x".parse().expect("v"));
        strip_inbound(&mut h);
        assert!(h.is_empty(), "{name} survived");
    }
}

#[test]
fn injected_headers_carry_the_fingerprint_and_verdict() {
    let out = fp_headers(&report("curl"), &identify(&report("curl"), &db()));
    let get = |k: &str| out.iter().find(|(n, _)| n == k).map(|(_, v)| v.clone());

    assert_eq!(get("x-fp-ja4").as_deref(), Some("t13i4906h2_0d8feac7bc37_7395dae3b2f3"));
    assert_eq!(get("x-fp-verdict").as_deref(), Some("curl-8.7.1-macos"));
    assert_eq!(get("x-fp-mismatch").as_deref(), Some("false"));
    assert!(get("x-fp-h2").is_some());
}

#[test]
fn an_unidentified_client_is_reported_as_unknown_not_omitted() {
    // Downstream must be able to tell "we looked and found nothing" from
    // "fpd was not in the path at all".
    let mut r = report("curl");
    r.tls.ciphers = vec![0x1301];
    let out = fp_headers(&r, &identify(&r, &db()));
    let verdict = out.iter().find(|(n, _)| n == "x-fp-verdict").map(|(_, v)| v.clone());
    assert_eq!(verdict.as_deref(), Some("unknown"));
}

/// No header value other than the documented exception may leak into an injected
/// header.
#[test]
fn no_cookie_or_authorization_value_reaches_an_injected_header() {
    let mut r = report("chrome");
    set_header(&mut r, "cookie", "session=SECRETVALUE");
    set_header(&mut r, "authorization", "Bearer SECRETTOKEN");
    let rendered = format!("{:?}", fp_headers(&r, &identify(&r, &db())));
    assert!(!rendered.contains("SECRETVALUE"));
    assert!(!rendered.contains("SECRETTOKEN"));
}

### Task 4: Structured logging

**Files:** `crates/fingerprint-probe/src/serve.rs`

One line per connection, the shape from design §5.5.

```
INFO  request  path=/api/products  ja4=t13i1516h2_8daaf6…  verdict=chrome-macos   ok
WARN  request  path=/api/login     ja4=t13i4906h2_0d8fea…  verdict=curl-8.7.1-macos
               ua_claims=chrome  mismatch=TRUE  ip=127.0.0.1

## Self-Review

**Spec coverage.** §5.5 `serve`, injected headers and inbound stripping → Tasks 1, 3, 5.
§6.4 verdict in the injected headers → Task 1. §10 resource bounds → Tasks 2 and 3.
Logging shape → Task 4.

**Deliberately excluded.** `fingerprint-tower` (M4c), the TUI and its admin socket (M6),
HTTP/2 upstreams.

**Known risks.**
1. **HTTP/1.1 upstream only.** Fine for the sidecar shape, where the upstream is a local
   application. An operator wanting h2 to the upstream is not served in v1, and the
   README must say so rather than leave it to be discovered.
2. **This is the first long-running component.** Everything before it ran once and
   exited. Connection limits and timeouts are load-bearing here in a way they were not
   before.
3. **A stub upstream is not a real application.** It proves headers arrive. It does not
   prove behaviour under a real framework's parsing, and a real deployment behind Caddy
   or nginx should be tried before claiming the sidecar works.
